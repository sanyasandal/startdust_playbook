# AZ footer

One AZ site footer from **One AZ v3.2 / Footer**, instance `13496:9714`.

The block is authored in the page body and moves itself into `body > footer`
on decoration. Its CSS hides the project's default `.footer` block only on
pages containing `az-footer`.

## Authoring

| Key | Value |
| --- | --- |
| Logo | A link to the home page; its text becomes the logo alt text |
| About | Short statement under the logo |
| Links | A list of links. Repeat the row for each column |
| Social | Links named LinkedIn, Facebook, YouTube, Instagram or X; rendered as labelled icons |
| Code | Job/approval code |

Columns stack below 768px.
