Frequently asked questions

What are miniapps? +

Miniapps are quick, powerful tools built into Playbook (or powered by trusted partners) that help you do things like remove backgrounds, upscale images, convert file formats, and more — all in just a few clicks.

Who can use miniapps? +

You can try out miniapps with any Playbook account! Some miniapps are free for all users, and some are included with a Pro or Team plan. Regardless, most miniapps have a few free runs so you can try them out now!

Do I need to download or install anything? +

Nope! Miniapps work directly in your browser inside Playbook — no downloads or extra software needed.Are there any limits on how often I can use miniapps?

Are there any limits on how often I can use miniapps? +

Most miniapps have generous usage limits, especially for Pro and Team users. If a limit applies, it will be clearly shown before you run the tool.

Are my files safe when using miniapps? +

Yes — your files are securely processed, and we never store your data longer than necessary. Partner-powered miniapps only access files for the purpose of completing your request. If a limit applies, it will be clearly shown before you run the tool.
