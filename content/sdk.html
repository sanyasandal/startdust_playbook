Frequently Asked Questions

How does Playbook SDK & API work?

Your development team first gets access to our SDK and API documentation, where they can generate an authentication key for their developer account to get started. The Playbook Media Library SDK includes three key components:

  • File Sync SDK - Sync user or client files seamlessly with Playbook's storage.
  • Front-End UX/UI SDK – Build a white-labeled media library with folders, subfolders, asset views, sharing, and search.
  • Advanced File Manager SDK – Enable bulk editing and access AI-powered editing tools.

What are some common use cases?

Our clients use Playbook SDK & API for:

  • Hosting user training material in their product
  • Managing and sharing media kits across multiple touchpoints from a single source
  • Building a custom media library within their product, complete with collaboration and sharing features
